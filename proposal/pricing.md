# Pricing

## Recommended approach
We recommend a fixed-fee engagement for the required scope, with a clearly defined not-to-exceed amount and a separate optional estimate for desired enhancements.

## Base engagement estimate
- Reports remediation (`R1`): 2 days
- Restocking recommendations (`R2`): 3 days
- Automated browser testing (`R3`): 2 days
- Architecture documentation (`R4`): 1 day
- Project management, review, and handoff: 1 day

**Total estimated effort:** 9 days

## Not-to-exceed proposal
- Fixed-fee not-to-exceed: **$28,000**
  - This covers the required scope described in §3.1.
  - Includes code changes, browser tests, architecture documentation, and two review cycles.

## Optional enhancements
If Meridian wants to extend the work to the desired items in §3.2, we can provide a separate scope and estimate for:
- UI modernization
- extended internationalization support
- dark mode

These enhancements would be scoped after the required work is confirmed and would be quoted separately as a follow-on phase.

## Pricing assumptions
- Meridian provides timely access to current system requirements and stakeholders for clarifications.
- The scope remains limited to the existing Vue + FastAPI application and JSON-backed data model.
- No additional backend platform or database migration is required.
- Any significant change in requirements or new feature requests beyond §3.1 will be estimated separately.
